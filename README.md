# Yaeori

Небольшое веб-приложение в дизайне JUUNIBI: графитовая тёмная и светлая темы, один акцентный цвет (золото, сакура, нефрит, фиалка или свой), левое меню и настройки. Круглой кнопки-аватара нет.

## Запуск (Windows)

Дважды щёлкните `Yaeori.bat`. Если Node.js 20+ нет, он скачает переносную версию в `.runtime` (с проверкой SHA-256), установит зависимости, проверит типы, соберёт проект, найдёт свободный порт (с 4173) и откроет браузер.

Параметры: `--dev`, `--no-open`, `--skip-checks`, `--port N`. На других ОС: `npm start`.

## Настройки

Страница «Настройки» (как у JUUNIBI): оглавление, поиск (клавиша `/`), сворачиваемые карточки, у каждой кнопка «По умолчанию».

- **Подключение:** ключ Cloud.ru и адрес API. Ключ хранится только на сервере в `data/settings.json` и в браузер не отдаётся. Кнопка «Проверить» проверяет ключ и получает список моделей.
- **Модель:** основная и запасная.
- **Внешний вид:** тема, акцент, размер текста, плотность, скругления.
- **Данные:** выгрузка и загрузка внешнего вида в файл (без ключа), сброс.
- **О программе:** версия и горячие клавиши (`Alt+1`, `Alt+2`, `/`).

Запросы на изменение настроек принимаются только со страницы самого приложения (проверка Origin), адрес API должен быть https.

## Разработка

```
npm install
npm run dev        # режим разработки (Vite)
npm run typecheck
npm run build
```

Стек: TypeScript (strict) и Vite, без фреймворков. Исходники в `src/`: `style.css` (цвета и компоненты), `accents.ts` (акценты), `main.ts` (меню и страницы).
