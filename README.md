# Yaeori

Небольшое веб-приложение в дизайне JUUNIBI: графитовая тёмная и светлая темы, один акцентный цвет (золото, сакура, нефрит, фиалка или свой), левое меню и настройки. Круглой кнопки-аватара нет.

## Запуск (Windows)

Дважды щёлкните `Yaeori.bat`. Если Node.js 20+ нет, он скачает переносную версию в `.runtime` (с проверкой SHA-256), установит зависимости, проверит типы, соберёт проект, найдёт свободный порт (с 4173) и откроет браузер.

Параметры: `--dev`, `--no-open`, `--skip-checks`, `--port N`. На других ОС: `npm start`.

## Главная: карта беседы и чат

Слева карта беседы в духе «Второго мозга». В центре Yaeori (двойное кольцо), чаты — крупные узлы с подписью капсом, сообщения — мелкие квадраты вокруг них (жёлтые — ваши, фиолетовые — ответы). Длинные ответы и последнее сообщение чата — крупные точки с подписью при приближении. Файлов и папок нет, узлы — только чаты и сообщения.

- **Связи.** От центра к чатам и от чата к его сообщениям идут линии, затухающие с расстоянием. Между чатами рисуются дуги: сервер находит сообщения из разных чатов с общими значимыми словами (от 5 букв, слово встречается не больше чем в 8 сообщениях). Связи не хранятся отдельно, а считаются по тексту при каждом запросе (`/api/graph`), поэтому всегда соответствуют базе. При наведении на сообщение его связи подсвечиваются, в подсказке видно общие слова.
- **Внешнее кольцо «Система»:** значки Ключ Cloud.ru, Модель, База SQLite, Чаты, Тема карты. Цвет показывает состояние (нет ключа или модели — предупреждающий), клик по ключу и модели открывает нужный раздел настроек.
- **Эффекты:** сетка из шестиугольников на фоне, круги-ориентиры, пульсирующий центр, мерцание квадратов, свечение у чатов, выделенного и найденного, вспышка у нового сообщения, плавные переходы между раскладками.
- **Раскладки:** Кольца, Круг, Соты, Плита (карточки-квадраты), HUD (секторы, шкала и луч), Сила (физика связей). **Группировка:** по чатам или по дням.
- **Управление:** колесо — масштаб, перетаскивание — сдвиг, наведение — текст, клик — открыть чат, двойной щелчок по чату — свернуть или развернуть его сообщения, по пустому месту — центрировать. Кнопка «Показ» включает автопилот: камера по очереди облетает чаты, любое действие мышью его останавливает.
- **Панель «Настройки карты»:** поиск, раскладка, группировка, вращение, сила связей, размер узлов, подписи, связи, «Развернуть всё», «Свернуть всё», «Центрировать», темы карты (По акценту, Океан, Неон, Бордо, Бумага, у выбранной метка «Используется»), «Скачать PNG», «По умолчанию». Всё сохраняется в браузере.

Справа чат: ответы приходят потоком, кнопка «Стоп» останавливает ответ (полученная часть сохраняется), есть выбор чата, «Новый» и «Удалить». Нужны ключ и модель в «Настройках».

## База данных

История чатов хранится в SQLite: `data/yaeori.sqlite3` (библиотека sql.js, чистый JS, ничего не нужно собирать под Windows). Файл пишется атомарно; повреждённый файл не затирается, а откладывается как `.broken-…`. Папка `data/` не попадает в git. Резервная копия — просто скопировать файл.

## Настройки

Страница «Настройки» (как у JUUNIBI): оглавление, поиск (клавиша `/`), сворачиваемые карточки, у каждой кнопка «По умолчанию».

- **Подключение:** ключ Cloud.ru и адрес API (OpenAI-совместимый, `/chat/completions`). Ключ хранится только на сервере в `data/settings.json` и в браузер не отдаётся. Кнопка «Проверить» проверяет ключ и получает список моделей.
- **Модель:** основная и запасная.
- **Внешний вид:** тема, акцент, размер текста, плотность, скругления.
- **Данные:** выгрузка и загрузка внешнего вида в файл (без ключа), сброс.
- **О программе:** версия и горячие клавиши (`Alt+1`, `Alt+2`, `/`).

Запросы на изменение настроек принимаются только со страницы самого приложения (проверка Origin), адрес API должен быть https.

## Разработка

```
npm install
npm run dev        # режим разработки (Vite)
npm run typecheck
npm run build
```

Стек: TypeScript (strict) и Vite, без фреймворков. Исходники в `src/`: `style.css` (цвета и компоненты), `accents.ts` (акценты), `main.ts` (меню и страницы).

## Ошибки Cloud.ru

Чат показывает причину и что делать: коды 400, 401, 402, 403, 404, 409, 413, 422, 429, 5xx и сетевые сбои (нет адреса, отказ соединения, обрыв, подменённый сертификат, нет ответа за 60 секунд). Полный список — в «Настройках» → «Модель» → «Что значат ошибки Cloud.ru». Если основная модель не ответила, чат сам пробует запасную. Справка собрана по документации Cloud.ru: лимит 20 запросов в секунду на ключ, срок действия ключа и «интервал работы».

## Мозг

На главной карта показывает «мозг» Yaeori (вкладка «Мозг»; «Беседы» — прежняя карта чатов).
- **Память.** После каждого ответа модель Cloud.ru выделяет из беседы факты. Они сохраняются в SQLite (таблица `memories`) и учитываются в следующих ответах: до 12 самых подходящих попадают в системную подсказку.
- **Нейроны и области.** Каждый факт — точка, темы — области мозга. Повтор факта усиливает его (до ×20), а не создаёт копию.
- **Свежая и долгая память.** Свежая — не старше 3 дней, долгая — подтверждена 3 раза и больше, «забывается» — старше 14 дней без повторов. Забытое только тускнеет, из базы не удаляется.
- **Связи.** Два факта из разных тем, у которых есть общая тема, соединены линией; чем больше общих тем, тем толще линия.
- **Развитие.** Ползунок под картой переносит во времени, кнопка «Рост» проигрывает рост мозга. Уровень растёт с числом воспоминаний: Зародыш, Росток, Ученик, Знаток, Мудрец.
- **Управление.** «Настройки» → «Память»: выключить запоминание, посмотреть и удалить факты, «Забыть всё», «Вспомнить из бесед» (прочитать уже написанное).

### Векторная и графовая память
Воспоминания получают векторы (эмбеддинги Cloud.ru, `/v1/embeddings`; модель находится сама по именам `embed`/`bge`/`e5`/`gte`, можно задать вручную). Поиск идёт по словам, темам и смыслу, затем граф подтягивает соседей: по общим темам и по близости векторов. На карте такие связи пунктирные («по смыслу»). Панель: «Список → Память → Векторы». Без модели эмбеддингов всё работает по словам и темам.

### Порядок в памяти и резервная копия
- В «Список → Память» есть проверка дублей (по смыслу и по словам) и противоречий (спрашивает модель Cloud.ru). Объединить, выбрать верное или оставить как есть.
- Воспоминание можно править (✎) и закреплять (📌): закреплённое не забывается и чаще попадает в ответ.
- Настройки → Данные → «Сохранить копию» сохраняет беседы, память и внешний вид в один файл (без ключа), «Загрузить копию» заменяет ими текущие данные.

## Эволюция памяти и чат

- **Затухание.** Воспоминание, к которому давно не обращались, тускнеет: сила × 0.5^(дни / 45). Ниже порога 0,3 оно уходит в «Архив и история» (там его можно вернуть). Обращение в разговоре сбрасывает отсчёт, закреплённые не затухают.
- **История фактов.** При противоречии проигравший факт не удаляется, а помечается «заменено» со ссылкой на победившего.
- **Сжатие.** В «Порядке в памяти» старые (>21 дня) россыпи из 4+ воспоминаний одной темы предлагается свернуть в одно обобщённое; исходные уходят в историю.
- **Резюме беседы.** Всё, что старше последних 10 сообщений, сжимается моделью в короткий пересказ; он идёт в контекст ответа и в выделение фактов.
- **Чат.** Потоковая разметка чинит незавершённые `**`, `` ` ``, ссылки и блоки кода; списки, заголовки, курсив и ссылки; текст выводится плавно.

## Сущности и время

- **Сущности и связи.** Из разговора выделяются люди, места, организации, техника и связи вида «кто — отношение — с кем». В списке на вкладке «Связи» они собраны с воспоминаниями; на карте добавился тип связи «Сущность» (штриховая линия).
- **Усиление по сущностям.** Если в вопросе названо имя или место (в любом падеже), все связанные воспоминания поднимаются в выдаче; частая сущность усиливает слабее.
- **Время действия.** У факта могут быть даты «с» и «до». Для отношений «живёт», «работает», «должность», «учится» новый факт автоматически закрывает прежний датой. Прошлые факты ниже в выдаче и подаются модели с пометкой «было раньше».
- **Рабочая память беседы.** Что запомнилось в этом чате за последние сутки, всегда попадает в контекст ответа (до четырёх воспоминаний), даже если вопрос о другом.

## Карта: сущности и живой поток

- Тип связи «Сущность» включает на карте ромбики-сущности: каждый стоит в центре своих воспоминаний. Щелчок по ромбику (или по сущности в списке) подсвечивает все её воспоминания и ведёт к ним штриховые линии.
- Живой поток ярче: у комет длинный хвост со свечением, а цвет показывает событие: фиолетовый и бирюзовый — «вспомнила», мятный — «запомнила» (вспышка с лучами в новой точке), золотой — «закрепила». Свежие точки мягко пульсируют.

## Чистота карты

В раскладке «Сектора» убрана сетка из шестиугольников (вместо неё мягкое свечение у центра), спицы к отделам затухают у центра, а пунктир «нейрон → беседа» виден только при наведении и выборе. Подписи отделов, бесед и сущностей расставляются без наложений: сначала наведённые и выбранные, затем отделы по размеру; лишние скрываются. Текст на карте — системный шрифт с обводкой цвета фона, холст рисуется с плотностью до ×3.
